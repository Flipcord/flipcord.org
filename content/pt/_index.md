# O que é Flipcord?

![O que é Flipcord?](../images/flipcord-org-pt.webp)

**Flipcord é um nome para objetos de manipulação manual concebidos para se moverem entre os dedos — virando, dobrando, rodando, girando e passando de uma mão para a outra.**

O nome foi criado por **Oleksandr Kostyuk** para dar a estes objetos um nome simples em inglês, sem recorrer a significados associados a terminologias religiosas, culturais ou tradicionais já existentes.

A palavra reúne duas ideias básicas:

**FLIP** — o movimento característico do objeto na mão.

**CORD** — a ligação flexível entre os seus elementos.

Um Flipcord não tem de obedecer a uma forma ou a um material específico. Pode ser composto por contas de madeira, placas articuladas, segmentos moldados ou outros elementos interligados. Madeira, metal, resina e outros materiais podem fazer parte do seu design.

Mas o material é apenas o ponto de partida.

**A característica que define um Flipcord é o movimento.**

Quando o objeto se desloca entre os dedos, as mãos envolvem-se com ritmo, precisão, coordenação e transições controladas. Isto torna o Flipcord interessante não apenas como objeto, mas também como uma forma de explorar a relação entre **o movimento, as mãos e a mente**.

Esta perspetiva também levanta questões relevantes para áreas como a **Fisioterapia (PT)**: poderão determinados movimentos controlados das mãos e dos dedos ser úteis em exercícios relacionados com mobilidade, coordenação ou perceção sensorial?

São questões que requerem exploração e investigação — **não constituem alegações médicas sobre o Flipcord.**

**Flipcord é o nome.**

**O movimento é a ideia.**
